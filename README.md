# 🚀 سیستم سئو و تولید محتوای حرفه‌ای

یک سیستم کامل و حرفه‌ای برای تحقیق کلمات کلیدی، برنامه‌ریزی محتوا، تولید مقالات سئو شده و انتشار خودکار روی وردپرس

## 🌐 دو روش استفاده

### 1. وب اپلیکیشن (توصیه می‌شود)
رابط کاربری گرافیکی مدرن با React

```bash
npm run dev
```

🔗 **[راهنمای کامل وب اپلیکیشن →](./WEB-GUIDE.md)**

### 2. CLI (خط فرمان)
رابط خط فرمان تعاملی

```bash
npm start
```

## ✨ ویژگی‌ها

### 1️⃣ مدیریت دسته‌بندی‌ها
- دریافت و ذخیره دسته‌بندی‌های سایت
- اولویت‌بندی دسته‌بندی‌ها
- مدیریت کامل (ویرایش، حذف، نمایش)

### 2️⃣ تحقیق کلمات کلیدی
- استفاده از Google Suggest API
- تولید کلمات کلیدی مرتبط (Variations)
- تولید Long-tail Keywords
- طبقه‌بندی کلمات کلیدی:
  - Informational (آموزشی)
  - Commercial (تجاری)
  - Transactional (خرید)
  - Navigational (راهبری)
- تخمین حجم جستجو و سختی رقابت

### 3️⃣ ساختار Pillar-Cluster
- ایجاد ساختار Pillar Content (محتوای اصلی)
- گروه‌بندی کلمات کلیدی به Clusters
- تولید Mind Map به صورت JSON و Markdown
- اولویت‌بندی هوشمند محتوا

### 4️⃣ تقویم محتوایی
- ایجاد تقویم روزانه برای انتشار محتوا
- برنامه‌ریزی بر اساس اولویت و حجم جستجو
- خروجی JSON و Markdown
- امکان تنظیم تعداد محتوا در روز

### 5️⃣ تولید محتوای سئو شده
- تولید خودکار Outline مقاله
- ساخت محتوای HTML با Schema.org
- متا تگ‌های کامل (Title, Description, OG Tags)
- لینک‌های داخلی هوشمند
- پیشنهاد تصاویر با Alt Tags
- محاسبه تعداد کلمات و زمان خواندن

### 6️⃣ انتشار روی وردپرس
- اتصال به WordPress REST API
- انتشار خودکار مقالات
- مدیریت دسته‌بندی‌ها
- آپلود تصاویر
- پشتیبانی از Draft و Publish
- برنامه‌ریزی انتشار

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18 یا بالاتر
- npm یا yarn
- وردپرس با REST API فعال

### مراحل نصب

1. کلون کردن پروژه:
```bash
git clone <repository-url>
cd seo-content-system
```

2. نصب dependencies:
```bash
npm install
```

3. تنظیم فایل محیطی:
```bash
cp .env.example .env
```

4. ویرایش فایل `.env`:
```env
# WordPress Configuration
WORDPRESS_URL=https://your-site.com
WORDPRESS_USERNAME=your-username
WORDPRESS_APP_PASSWORD=your-app-password

# OpenAI Configuration (اختیاری)
OPENAI_API_KEY=your-openai-api-key

# Content Configuration
DAILY_CONTENT_COUNT=3
MIN_WORD_COUNT=1500
MAX_WORD_COUNT=3000
CONTENT_LANGUAGE=fa
```

### راه‌اندازی WordPress

برای اتصال به وردپرس، باید Application Password ایجاد کنید:

1. وارد پنل مدیریت وردپرس شوید
2. به `Users → Profile` بروید
3. به بخش `Application Passwords` بروید
4. یک نام برای Application وارد کنید (مثلا: SEO Content System)
5. روی `Add New Application Password` کلیک کنید
6. رمز تولید شده را کپی کرده و در فایل `.env` قرار دهید

### فرآیند کار (گام به گام)

#### مرحله 1: تعریف دسته‌بندی‌ها

1. از منو `📁 مدیریت دسته‌بندی‌ها` را انتخاب کنید
2. `افزودن دسته‌بندی‌ها` را بزنید
3. برای هر دسته‌بندی اطلاعات زیر را وارد کنید:
   - نام دسته‌بندی
   - اسلاگ (URL-friendly)
   - توضیحات
   - اولویت (1-10)

مثال:
```
نام: آموزش برنامه‌نویسی
اسلاگ: programming
توضیحات: مقالات آموزشی برنامه‌نویسی
اولویت: 9
```

#### مرحله 2: تحقیق کلمات کلیدی

1. `🔍 تحقیق کلمات کلیدی` را انتخاب کنید
2. سیستم به طور خودکار برای تمام دسته‌بندی‌ها کلمات کلیدی تولید می‌کند
3. نتایج در `data/keywords/` ذخیره می‌شود

خروجی نمونه:
```json
[
  {
    "keyword": "آموزش برنامه‌نویسی",
    "searchVolume": 4500,
    "difficulty": 65,
    "type": "informational"
  }
]
```

#### مرحله 3: ساخت ساختار Pillar-Cluster

1. `🏗️  ساخت ساختار Pillar-Cluster` را انتخاب کنید
2. سیستم کلمات کلیدی را به صورت خوشه‌ای گروه‌بندی می‌کند
3. Mind Map به صورت JSON و Markdown تولید می‌شود

ساختار Pillar-Cluster:
```
Pillar Content (محتوای اصلی)
├── Cluster 1: محتوای آموزشی
│   ├── کلمه کلیدی 1
│   ├── کلمه کلیدی 2
│   └── ...
├── Cluster 2: محتوای تجاری
└── Cluster 3: محتوای خرید
```

#### مرحله 4: ایجاد تقویم محتوایی

1. `📅 ایجاد تقویم محتوایی` را انتخاب کنید
2. تعداد روزهای تقویم را وارد کنید (مثلا 30)
3. تقویم در `data/calendar/` ذخیره می‌شود

نمونه خروجی:
```markdown
## روز 1: 2024-01-15

1. 🎯 آموزش برنامه‌نویسی (Pillar)
2. 📄 چگونه برنامه‌نویسی را شروع کنیم (Cluster)
3. 📄 بهترین زبان‌های برنامه‌نویسی (Cluster)
```

#### مرحله 5: تولید محتوا

1. `✍️  تولید محتوا` را انتخاب کنید
2. محدوده تولید را انتخاب کنید:
   - محتوای امروز
   - تعداد مشخص
   - همه محتوا
3. محتوا در `data/content/` ذخیره می‌شود

هر مقاله شامل:
- HTML کامل با Schema.org
- متا تگ‌ها
- لینک‌های داخلی
- پیشنهاد تصاویر

#### مرحله 6: انتشار روی وردپرس

1. `📤 انتشار روی وردپرس` را انتخاب کنید
2. محدوده انتشار را مشخص کنید
3. حالت انتشار را انتخاب کنید (Publish یا Draft)

### فرآیند کامل (اتوماتیک)

برای اجرای تمام مراحل به صورت خودکار:

1. `🔄 فرآیند کامل` را انتخاب کنید
2. سیستم تمام مراحل را به ترتیب اجرا می‌کند:
   - دریافت دسته‌بندی‌ها
   - تحقیق کلمات کلیدی
   - ساخت Pillar-Cluster
   - ایجاد تقویم
   - تولید محتوا

## 📊 خروجی‌ها

### Mind Map (Markdown)

```markdown
# آموزش برنامه‌نویسی

## 1. محتوای آموزشی و اطلاعاتی
**اولویت:** 1

   1. **آموزش برنامه‌نویسی چیست**
      - حجم جستجو: 4500
      - سختی: 45

   2. **چگونه برنامه‌نویسی یاد بگیریم**
      - حجم جستجو: 3800
      - سختی: 52
```

### تقویم محتوایی (JSON)

```json
[
  {
    "date": "2024-01-15T00:00:00.000Z",
    "dateFormatted": "2024-01-15",
    "content": [
      {
        "type": "pillar",
        "title": "آموزش برنامه‌نویسی",
        "keyword": {...},
        "status": "scheduled"
      }
    ]
  }
]
```

### محتوای تولید شده (HTML)

```html
<article class="seo-content" itemscope itemtype="http://schema.org/Article">
  <header>
    <h1 itemprop="headline">آموزش برنامه‌نویسی</h1>
  </header>

  <div class="introduction" itemprop="description">
    <p>در این مقاله جامع، به بررسی کامل آموزش برنامه‌نویسی می‌پردازیم...</p>
  </div>

  <!-- محتوای اصلی -->
</article>
```
